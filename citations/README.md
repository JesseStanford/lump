# citations

- `references.bib` - BibTeX, for Zotero, LaTeX or Word (via Zotero/JabRef import).
- `references.csv` - the same list as a table; fill `used_for` with the parameter rule_ids a source supports.
- Every row in parameters/parameters.csv names its source; keep those names matching the keys here.

To add a source: add a BibTeX entry, add a CSV row with the same key, and cite the key in the parameter row.
